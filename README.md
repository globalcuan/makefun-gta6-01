# Costa Serena

Costa Serena is a small open-world driving and crime game set in a sunlit coastal city. Steal cars, evade police, and follow a four-part story across the city, harbor, bank, and beach.

## Controls

- **WASD**: move or drive
- **Shift**: run
- **E**: enter or exit a car
- **Space**: handbrake
- **F**: punch
- **M**: mute or unmute
- **Mouse**: look around
- **Esc**: pause

## Run

From the repository root, run `node serve.ts`, then open [http://localhost:8080](http://localhost:8080).
