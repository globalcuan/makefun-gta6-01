# Costa Serena

Explore a sunlit coastal city, take cars through busy streets, evade police, and follow a four-mission story from a courier run to a bank escape.

## Controls

- **WASD** move or drive; **Shift** run
- **E** enter or exit a nearby car
- **Space** handbrake
- **F** punch a nearby pedestrian
- **M** mute or unmute audio
- **Mouse** look around; **Esc** pause and save

## Run locally

From the repository root, run `node serve.ts`, then open http://localhost:8080.
